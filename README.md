# Polygon Plus
Extensão para Chrome e Firefox que melhora o visual e a usabilidade de https://polygon.codeforces.com

## Instalação
**Chrome/Edge/Brave:** chrome://extensions → ativar "Modo do desenvolvedor" → "Carregar sem compactação" → escolher esta pasta.
**Firefox:** about:debugging#/runtime/this-firefox → "Carregar extensão temporária…" → escolher `manifest.json`.
# BetterPolygonCodeforces

## Importar zip
Na página **Problems** aparece o botão **Importar zip**: ele lê um pacote `.zip` gerado pelo Polygon e cria um novo problema com enunciados, limites, arquivos, checker, validator, interactor, soluções (com tags), testes (grupos, pontos, exemplos) e tags. Vincular a contests e commit ficam manuais.
Antes, cole sua **API key/secret** (Settings → API no Polygon) no popup da extensão.
